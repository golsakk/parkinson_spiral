# تشخیص پارکینسون از نقاشی مارپیچ

ابزار پژوهشی برای تشخیص الگوهای لرزش در نقاشی مارپیچ.

## نحوه استفاده
عکس مارپیچ یا موج رو آپلود کن، دکمه تحلیل رو بزن.

## مدل
MobileNetV2 با Transfer Learning روی دیتاست Kaggle Parkinson's Drawings.

## محدودیت‌ها
این ابزار جایگزین تشخیص پزشکی نیست. فقط برای پژوهش.
